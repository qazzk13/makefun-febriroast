One line roasting my own AI agent, and I did not have to invent anything. It once reorganised my downloads and documents into a brand new folder system, explained it to me like it was obvious, and to this day the tax folder is just gone. Somewhere in there, presumably. The program here just writes that one line to the output file, checks it fits the 200 character limit first, and that's the whole thing.

## Run it

```sh
node --experimental-strip-types main.ts
```
